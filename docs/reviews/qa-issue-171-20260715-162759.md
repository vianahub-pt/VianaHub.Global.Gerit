## Detalhamento da Validação

### CA1 — Code property
- **Esperado:** string obrigatória com max 50 caracteres
- **Implementado:** public string? Code { get; private set; } no Domain Entity, mapeado como NVARCHAR(50), HasMaxLength(50), IsRequired() no Mapping
- **Observação:** A propriedade C# é string? (nullable) por consistência com Name/Description existentes, mas a constraint NOT NULL é aplicada a nível de BD via .IsRequired(). Segue o padrão do codebase.

### CA2 — AddressTypeTranslationEntity
- **Esperado:** FK para AddressTypeId, unique por (AddressTypeId, LanguageCode)
- **Implementado:**
  - FK: HasForeignKey(x => x.AddressTypeId) com cascade delete e constraint nomeada FK_AddressTypeTranslations_AddressTypes_AddressTypeId
  - PK composta: HasKey(x => new { x.AddressTypeId, x.LanguageCode }).HasName("PK_AddressTypeTranslations")
  - Unique index redundante: UQ_AddressTypeTranslations_AddressType_Language (mesmo padrão do PartyTypeTranslation)

### CA3 — Description NVARCHAR(500)
- **Esperado:** NVARCHAR(500) - maior que 300
- **Implementado:** .HasColumnType("NVARCHAR(500)").HasMaxLength(500).IsRequired()
- **Observação:** Alinhado com PartyTypeTranslationMapping que também usa NVARCHAR(500). Consistente.
