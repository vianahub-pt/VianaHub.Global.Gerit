## Bugs Encontrados

### Bug 1 — Repositórios não registados no DependencyInjection.cs (Crítico)
- **Severidade:** Crítica
- **Localização:** src/VianaHub.Global.Gerit.Infra.IoC/DependencyInjection.cs
- **Descrição:** Os repositórios PartyTypeDataRepository e PartyTypeTranslationDataRepository não foram registados no container de DI. O ficheiro DependencyInjection.cs contém registos para todas as outras interfaces/repositórios do domínio Business (ex: AddressTypeDataRepository, StatusTypeDataRepository, etc.), mas as novas interfaces IPartyTypeDataRepository e IPartyTypeTranslationDataRepository estão ausentes.
- **Impacto:** Qualquer tentativa de injetar IPartyTypeDataRepository ou IPartyTypeTranslationDataRepository via construtor resultará em InvalidOperationException em runtime.
- **Evidência:** Linhas 237-279 do DependencyInjection.cs contêm todos os registos de repositórios Business mas nenhum inclui PartyType.
- **Correção necessária:** Adicionar:
  `csharp
  services.AddScoped<IPartyTypeDataRepository, PartyTypeDataRepository>();
  services.AddScoped<IPartyTypeTranslationDataRepository, PartyTypeTranslationDataRepository>();
  `

### Bug 2 — Seed Data não implementado (Médio)
- **Severidade:** Média
- **Localização:** src/VianaHub.Global.Gerit.Infra.Data/Seeders/DatabaseSeeder.cs
- **Descrição:** A issue especifica que o seed "Individual=1, Organization=2" deve ser adicionado ao DatabaseSeeder, mas não foi implementado. O ficheiro DatabaseSeeder.cs não contém referências a PartyTypeEntity.
- **Nota:** Este ponto não consta como critério de aceite formal, mas é mencionado nos "Pontos de Atenção" da issue. Pode ser intencional para um PR separado.

### Bug 3 — Ausência de validadores FluentValidation (Baixo)
- **Severidade:** Baixa
- **Localização:** src/VianaHub.Global.Gerit.Domain/Validators/Business/
- **Descrição:** Não foram criados validadores FluentValidation para PartyTypeEntity nem PartyTypeTranslationEntity. O padrão do projeto regista validadores para todas as entidades de domínio similares (AddressType, FileType, StatusType, etc.).
- **Nota:** Pode ser intencional para uma fase posterior.
